# Security, Encryption & Safety Controls

## Overview
Because the application interacts with external social networks and handles OAuth credentials, security and safety safeguards are enforced at every layer of the system.

## 1. Zero-Scraping Guarantee
- Scraping or headless browser automation (Playwright, Puppeteer, Selenium) is strictly prohibited for LinkedIn and X publishing.
- Scraping violates platform Terms of Service and creates severe account ban risks.
- All publishing operations use authenticated official APIs (`/rest/posts` for LinkedIn, `/2/tweets` for Twitter).

## 2. AES-256-GCM Token Encryption at Rest
All OAuth access tokens, refresh tokens, and API client secrets stored in the database are encrypted at rest using AES-256-GCM authenticated encryption:
- Encryption implementation: `src/packages/config/crypto.ts`
- Key requirement: A 256-bit key provided via `ENCRYPTION_SECRET` (64 hexadecimal characters).
- Cryptographic construction:
  - Random 16-byte initialization vector (IV) generated per ciphertext.
  - 16-byte authentication tag generated by GCM cipher.
  - Format: `iv:authTag:encryptedData` (all hex encoded).
  - Any ciphertext tampering or key mismatch fails immediately during decryption.

## 3. Sensitive Topic Exclusion Filter
Before any content is approved or published, the `SafetyService` (`src/packages/publishers/safety.service.ts`) scans the text against sensitive exclusion categories:
- **Political Controversies**: Elections, political candidates, policy debates.
- **Medical & Health Claims**: Diagnostic statements, medical advice, vaccine debates.
- **Financial & Investment Advice**: Stock tips, crypto trading, financial guarantees.
- **Harassment & Defamation**: Unsubstantiated allegations against individuals or corporations.

If a sensitive keyword or stemmed root is detected, publishing is immediately aborted with a typed `SafetyViolationError`.

## 4. Daily Rate Limiting & Safety Guard
To protect developer accounts from automated spam penalties or sudden platform rate limit suspensions:
- The system enforces `MAX_POSTS_PER_DAY` (default: 2 publications per 24 hours).
- The `PublishingCoordinator` queries the database for publications within the last 24 hours before dispatching calls to external platform APIs.

## 5. Secret Masking in Structured Logs
The JSON logger (`src/packages/config/logger.ts`) automatically scrubs known sensitive keys from log output:
- Redacted fields: `password`, `token`, `secret`, `apiKey`, `authorization`, `accessToken`, `encryptionSecret`.
- Sensitive string patterns (like OpenAI, Anthropic, or Gemini API keys) are masked with `[REDACTED]`.
