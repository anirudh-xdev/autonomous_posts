# Database Skill

## Purpose
Explains how data is structured, indexed, queried, and migrated across the database layer. Covers Prisma ORM client management, repository boundaries, dual SQLite/PostgreSQL setup, and seeding.

## When to Use
- When modifying entity schemas (Trend, ContentDraft, Publication, VoiceProfile, AgentRun).
- When running Prisma migrations or generating the Prisma client (`pnpm prisma:generate`).
- When switching between local SQLite development and production PostgreSQL/Supabase.
- When writing custom repository queries or analytics aggregations.

## Dual Schema Strategy
To support both zero-setup local development and high-throughput production deployments:
1. `prisma/schema.prisma` (SQLite):
   - Used for local development and fast unit testing.
   - Provider: `sqlite`, URL: `file:./dev.db`.
   - Native strings for JSON serialization and boolean integers.
2. `prisma/schema.postgres.prisma` (PostgreSQL):
   - Used for production deployments (Supabase, Neon, AWS RDS).
   - Provider: `postgresql`, native `Json` types, enums, and optimized B-tree indexes.

## Core Entities & Relationships
- **`Trend`**: Canonical topic discovered by trend engine.
  - Fields: `id`, `title`, `slug`, `primaryUrl`, `score`, `scoringRationale`, `status` (`DISCOVERED`, `RESEARCHED`, `DRAFTED`, `PUBLISHED`, `ARCHIVED`), `detectedAt`.
  - Relations: `hasMany(TrendEvidence)`, `hasOne(ResearchReport)`, `hasMany(ContentDraft)`.
- **`TrendEvidence`**: Raw candidate signal from a specific source.
  - Fields: `trendId`, `sourceName`, `sourceUrl`, `engagementScore`, `publishedAt`.
- **`ResearchReport`**: Deep technical dossier synthesized by Research Agent.
  - Fields: `trendId`, `summary`, `keyFacts`, `developerImplications`, `technicalTradeoffs`, `benchmarks`, `citations`.
- **`ContentDraft`**: Platform-tailored post generated by Content Engine.
  - Fields: `trendId`, `platform` (`LINKEDIN`, `X_SINGLE`, `X_THREAD`), `body`, `status` (`DRAFT`, `APPROVED`, `REJECTED`, `PUBLISHED`), `qualityScore`, `qualityReport`.
  - Relations: `hasMany(ContentVariant)`, `hasMany(Publication)`.
- **`Publication`**: Record of published post on external platforms.
  - Fields: `contentDraftId`, `platform`, `remotePostId`, `postUrl`, `publishedAt`, `metrics`.
- **`AgentRun`**: Audit trail of every automated execution.
  - Fields: `agentName`, `status` (`SUCCESS`, `FAILED`), `durationMs`, `promptTokens`, `completionTokens`, `errorDetails`.

## Repositories Layer
Direct Prisma access is encapsulated inside `src/packages/database/repositories/`:
- `trend.repository.ts`: Query active trends, high-scoring candidates, and status updates.
- `content.repository.ts`: Draft lifecycle, variant generation, and publication audit.
- `agent-run.repository.ts`: Execution audit trails and performance metrics.

## Important Commands
```bash
# Generate Prisma Client
pnpm prisma:generate

# Sync schema with SQLite (dev/test)
pnpm prisma db push

# Seed initial topics, sources, and voice profile
pnpm db:seed
```

## Important Files
- `prisma/schema.prisma`: SQLite schema definition.
- `prisma/schema.postgres.prisma`: PostgreSQL schema definition.
- `src/packages/database/client.ts`: Connection singleton.
- `src/packages/database/seed.ts`: 26 seed topics and default configurations.
